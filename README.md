# Cero Mata Cero — Tic Tac Toe

A two-player **Tic Tac Toe** game built with HTML, CSS, and JavaScript.

## Features

- Two-player X/O gameplay
- Turn indicator
- Win and tie detection
- Persistent session score using `sessionStorage`
- Score reset
- Play-again flow

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Run Locally

No installation is required.

```bash
git clone https://github.com/eduardolluis/Cero-mata-Cero.git
cd Cero-mata-Cero
```

Open `index.html` in your browser.
